EmojiHunter - Lab 9
===================

BEFORE YOU BUILD:
1. Download MobileNetV2.mlmodel from https://developer.apple.com/machine-learning/models/
   and drop it into EmojiHunter/Models/ (next to Emoji.swift). The project uses
   folder-synced groups, so Xcode picks it up automatically.
2. Open EmojiHunter.xcodeproj, select the EmojiHunter target > Signing & Capabilities,
   and choose your Team (personal team is fine).
3. Plug in your iPhone and run (Cmd+R). Run tests with Cmd+U.

The camera permission (Privacy - Camera Usage Description) is already set in the
target's Info tab.
